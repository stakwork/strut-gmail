# strut-gmail

The `stadeum/gmail` package for [strut](https://github.com/stakwork/strut):
each person connects their own Google account, and any workflow on the box
can read, search, draft and send their mail, as them.

A mailbox is whoever's token the run has. Every token is a person's own,
and the package keeps nothing: tokens are strut's secrets.

Nothing is published yet. The package will sit at this repository's root, and
a box will follow its `stable` branch:

```text
git+https://github.com/stakwork/strut-gmail@stable
```
